
# Reading Note – Week 1

**Article:** [MDN – The Box Model](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Box_model)

In this article, I learned how every element on a web page is treated as a rectangular box comprising four layers: **content, padding, border, and margin**.

I discovered the difference between the standard box model and the alternative box model using `box-sizing: border-box`.

Using `border-box` ensures that padding and borders do not unexpectedly expand an element's total width, making layouts much easier to control.
